# DevJobs

Projeto web full-stack com frontend estático e API Node.js/Express.

## Estrutura

- `frontend/`: HTML, CSS e JavaScript do cliente.
- `api/`: servidor Node.js, banco SQLite e código da API.

## Executar

### Frontend

Abra `frontend/index.html` no navegador ou use uma extensão de servidor estático.

### API

```powershell
cd api
npm install
npm start
```

A API ficará disponível em `http://localhost:3000`.
